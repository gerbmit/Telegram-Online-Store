# 🛒 Telegram Online Store

Асинхронный Telegram-бот интернет-магазина на **Python**, **aiogram 3** и **SQLAlchemy 2.0**.  
Проект построен по чистой слоистой архитектуре (`handlers`, `services`, `middlewares`, `keyboards`, `database`, `utils`) и включает полноценную витрину товаров, корзину с контролем остатков, оплату через платёжных провайдеров или **Telegram Stars**, тикет-поддержку и админ-панель.

---

## ✨ Возможности

### 🛍 Для покупателей
- **Каталог по категориям** — удобная inline-навигация по разделам и карточкам товаров с фото, описанием, артикулом, ценой и актуальным остатком.
- **Корзина и контроль склада** — выбор количества товара с проверкой доступных остатков, защита от дублей и автоматический подсчёт суммы.
- **Оформление заказа (FSM)** — пошаговый ввод данных доставки (ФИО, телефон, город, адрес, комментарий), подтверждение и возможность отмены на любом этапе (`/cancel` или `отмена`).
- **Оплата в Telegram** — поддержка платёжных провайдеров (ЮKassa, Stripe и др. в `RUB`) и автоматическое переключение на **Telegram Stars (`XTR`)**, если `PAYMENT_TOKEN` не указан.
- **Профиль, заказы и избранное** — история последних заказов, статистика покупок и сохранённые товары.
- **Обратная связь** — встроенный раздел поддержки для общения с администратором прямо в боте.

### 🛠 Админ-панель (`/admin`)
- **Управление категориями** — добавление и безопасное удаление категорий.
- **Управление товарами** — пошаговое добавление товаров с фото, ценой и количеством на складе, а также удаление позиций.
- **Работа с заказами** — фильтрация по статусам (`Новый`, `Оплачен`, `Отправлен`, `Завершен`, `Отменен`), смена статусов и автоматический возврат товаров на склад при отмене заказа.
- **Рассылка** — отправка текста, фото, видео или документов всем пользователям с соблюдением лимитов Telegram API.
- **Статистика** — количество пользователей, товаров, заказов и общий доход по оплаченным/завершённым заказам.

## 🧰 Стек технологий

- **Python 3.10+**
- **[aiogram 3](https://docs.aiogram.dev/)** — асинхронный фреймворк для Telegram Bot API (FSM, CallbackData, Middlewares)
- **[SQLAlchemy 2.0 (async)](https://www.sqlalchemy.org/)** + **aiosqlite** — асинхронная ORM и работа с SQLite (легко переводится на PostgreSQL через `DB_URL`)
- **python-dotenv** — загрузка конфигурации из `.env`

## 🚀 Быстрый запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/gerbmit/Telegram-Online-Store.git
cd Telegram-Online-Store
```

### 2. Создайте виртуальное окружение и установите зависимости
```bash
python -m venv venv

# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Настройте переменные окружения
Скопируйте шаблон `.env.example` в `.env` и заполните свои значения:
```bash
cp .env.example .env
```

Пример `.env`:
```env
BOT_TOKEN=1234567890:AAExampleTokenReplaceMe
PAYMENT_TOKEN=
ADMIN_IDS=123456789
DB_URL=sqlite+aiosqlite:///database.db
```

> 💡 Если оставить `PAYMENT_TOKEN` пустым, бот автоматически выставит счета в **Telegram Stars (`XTR`)**.

### 4. Запустите бота
```bash
python bot.py
```
При первом запуске база данных `database.db` и все таблицы создадутся автоматически.

## 📋 Основные команды

| Команда | Описание |
| --- | --- |
| `/start` | Запуск бота, регистрация и открытие главного меню |
| `/admin` | Вход в панель администратора (доступно ID из `ADMIN_IDS`) |
| `/cancel` | Отмена текущего шага (оформление заказа, добавление товара и т.д.) |
